# Convert

Convert é uma aplicação web simples para converter valores de moedas estrangeiras em reais brasileiros. O usuário informa um valor, escolhe uma moeda e visualiza o resultado formatado em BRL.

## Moedas disponíveis

- Dólar Americano (USD)
- Euro (EUR)
- Libra Esterlina (GBP)
- Yuan Chinês (CNY)

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

Não é necessário instalar dependências. Para abrir o projeto, clone o repositório e abra o arquivo `index.html` em um navegador:

```bash
git clone https://github.com/Samuelaraujo10/ConversorDeMoedas.git
cd ConversorDeMoedas
```

Depois, abra `index.html`. Se preferir, use uma extensão como Live Server no VS Code para servir a página localmente.

## Cotações

As cotações estão definidas diretamente no arquivo `script.js` e não são atualizadas automaticamente. Para alterar os valores usados na conversão, edite as constantes `USD`, `EUR`, `GBP` e `CNY` nesse arquivo.
